# Team Assignment: TTT with a Fixed Held-Out Test Set

## Goal

Measure how the model changes as it keeps learning from new images.

After every 100 adaptation images, evaluate the current model on the same fixed held-out test set. Never use the held-out images for training, tuning, or adaptation.

Keep the two experiments separate:

- Experiment A: Nguyen, CIFAR-10 and CIFAR-10-C.
- Experiment B: Tuong, CIFAR-100 classes 0–19.

For now, use the existing rotation-based online TTT models. Pseudo-labeling and training with only 100 examples are later experiments.

## Shared Evaluation Process

1. Load the starting checkpoint.
2. Evaluate it on the fixed held-out set before adaptation. Record this at 0 images.
3. Apply TTT to the next 100 adaptation images.
4. Pause adaptation and evaluate on the same held-out set.
5. Continue from the same adapted model and optimizer state.
6. Repeat until the adaptation stream ends.
7. If fewer than 100 images remain at the end, evaluate after that last group too.

The plot should show:

- X-axis: adaptation images processed, 0, 100, 200, 300, and so on.
- Y-axis: classification accuracy on the fixed held-out set.

The 100-image interval is the evaluation schedule. It does not mean the training batch size must be 100.

## Shared Rules

- Held-out images must never be used for adaptation, including rotation updates or pseudo-label updates.
- Class labels stay outside the adaptation function and are used only for scoring.
- Choose settings using development data, then lock them before the measured run.
- Do not use held-out accuracy to choose settings, pick the best checkpoint, or stop early.
- Keep the held-out set fixed throughout a run.
- Turn off dropout and model updates during evaluation.
- Evaluation must not change the next adaptation step.
- Save the code version, settings, seeds, and split locations.
- Report negative results and unresolved differences.
- Preserve earlier experiments and results.
- If the new held-out images were examined in earlier experiments, say so. Do not describe them as completely new data.
